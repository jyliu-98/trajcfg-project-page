# Project notes

This is a zero-build static website intended for GitHub Pages.

- Keep all public URLs relative so repository-subpath deployment continues to work.
- Preserve semantic HTML, keyboard-accessible tabs, visible focus states, and reduced-motion behavior.
- Keep the primary brand color `#9BCFBD`; use it as an accent rather than a full-page fill.
- Do not rename or remove media files without updating `script.js`.
- Paper and code links intentionally show `Coming soon` until public URLs are known.
- After content changes, run `tests/browser/smoke.test.sh` and preview through a local HTTP server.
